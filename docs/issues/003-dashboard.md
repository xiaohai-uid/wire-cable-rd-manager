# Issue 3: 统计仪表盘 + 不良率

## What to build

系统首页仪表盘。展示关键质量指标和趋势。

**包含**：
- **汇总卡片**：总测试数、合格数、不合格数、不良率（百分比）
- **趋势图**：近7天/30天的不良率折线图（使用 Canvas/SVG 绘制）
- **最新记录**：最近10条测试记录
- **快捷入口**：快速跳转到新增测试、查看报告

**API 层**：`GET /api/ledger/stats` 返回汇总统计数据
**前端层**：仪表盘页面（`index.html`），展示卡片、图表、列表

## Acceptance criteria

- [ ] 仪表盘显示总测试数、合格数、不合格数、不良率
- [ ] 不良率以百分比格式显示
- [ ] 显示不良率趋势折线图
- [ ] 显示最近10条测试记录
- [ ] 页面刷新后数据更新
