# Issue 2: 测试台账录入 + 自动判定

## What to build

完整的测试台账模块。这是系统最核心的功能，替代 Excel 台账。

录入测试数据时系统自动：
1. 计算三个测试值的**平均值**
2. 根据规格类型（上限/下限/范围/定性）自动**判定**合格/不合格
3. 不合格记录**红色高亮**显示
4. 支持按产品型号、批号、判定结果**筛选**

**数据库层**：test_ledger 表的写入和查询
**API 层**：`GET/POST /api/ledger`、`GET/PUT/DELETE /api/ledger/:id`
**前端层**：台账列表页（`ledger.html`）、新增记录页（`ledger-new.html`）含动态规格选择

## Acceptance criteria

- [ ] 可录入新测试记录（选择产品、填写测试项目、规格、三个测试值）
- [ ] 提交后自动计算平均值并显示
- [ ] 自动判定合格/不合格（四种规格类型都正确）
- [ ] 不合格记录在列表中红色高亮显示
- [ ] 可按产品型号、批号筛选
- [ ] 可编辑和删除记录
