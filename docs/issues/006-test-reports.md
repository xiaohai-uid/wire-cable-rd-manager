# Issue 6: 测试报告生成 + 导出

## What to build

从测试数据生成结构化测试报告。选择批次→系统自动汇总该批次的全部测试项目→生成格式化报告→可导出为 HTML/打印。

**包含**：
- 按批次号选择测试数据
- 自动填充产品信息、测试条件、测试项目表格
- 综合结论判定（全部合格则"合格"，否则列出不合格项）
- 报告编辑（补充审核人、批准人等信息）
- 导出为结构化 HTML（可直接在 Word 中打开）

**API 层**：
- `GET /api/reports`、`GET /api/reports/:id`
- `POST /api/reports/generate` — 从台账数据生成报告
- `GET /api/reports/:id/export` — 导出 HTML

**前端层**：报告列表页（`reports.html`）、报告生成页、报告预览页

## Acceptance criteria

- [ ] 可选择批次号自动生成测试报告
- [ ] 报告包含：封面、概述、测试条件、测试数据表格、结论、签名区
- [ ] 所有合格/不合格判定自动填充
- [ ] 可补充审核人、批准人信息
- [ ] 可导出为 HTML 文件（可用 Word 打开）
- [ ] 报告可保存和查看历史
