# 03 — 下钻明细

**What to build:** 点热力图上任意一个格子，**在同一页展开**该「产品 + 测试项」组合的
全部测试台账记录，不跳页、不打断思路。明细里能完整复核判定过程：
三次测量值、平均值、规格、判定结果、批号、测试日期。

关键细节：三次测量中**越界的那一次单独标红**，而不是整行含糊标红 ——
研发工程师需要区分「三次全坏」和「只有一次坏」，这是两种完全不同的问题。
同时把系统读出的判定规则显示出来（例如「min，阈值 20，单位 dB」），
让人能核对系统是否读懂了自己写的规格。

**Blocked by:** 02 — 质量热力图首页

**Status:** ready-for-agent

- [ ] 点击格子在同一页展开明细，不发生整页跳转
- [ ] 明细显示三次测量值、平均值、规格、判定、批号、测试日期
- [ ] 三次测量中越界的那一次单独标红，未越界的不标
- [ ] 显示该记录使用的判定规则（种类 + 阈值 + 单位）
- [ ] 规格无法识别时明确显示「规格无法识别，拒绝自动判定」，不显示合格或不合格
- [ ] 被选中的格子进入 URL，刷新后明细保持展开
- [ ] 该产品未配置此测试项时显示「未配置此测试项」，而不是一张空表
- [ ] 明细中每条记录可点击跳转到它所属批次的录入位置（在 04 落地前可先留出入口）
