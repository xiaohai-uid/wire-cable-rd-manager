# 04 — 批次录入网格

**What to build:** 把 1.0 版「一个批次开 12 次模态框」的录入方式整个换掉。
选定产品和批号后，该产品的测试模板决定网格铺出多少行 ——
每行是一个测试项和它的规格，右边三列是三次测量。
研发工程师手上的原始记录本来就是这样一张二维表，现在可以照抄进去（ADR 0003）。

像用电子表格一样操作：Tab 横向、Enter 纵向、方向键任意方向走位，
支持从 Excel 复制一块区域直接粘贴。每填完一行立刻显示平均值和判定，
当场发现异常值而不是保存后才知道。整批一次性保存 ——
一个批次对应一次提交，一次全成功或一次全失败，不出现「录了一半」。

**Blocked by:** 03 — 下钻明细

**Status:** ready-for-agent

- [ ] 选定产品与批号后，按测试模板自动铺出全部测试项行（含规格列）
- [ ] Tab 横向、Enter 纵向、方向键四向走位，全程不需要鼠标
- [ ] 支持从 Excel 复制多行多列区域，一次粘贴进网格
- [ ] 每行填完立刻显示平均值与判定，无需保存
- [ ] 保存前显示本批次判定摘要：合格 X / 不合格 Y / 未判定 Z
- [ ] 整批一次性保存，写入是原子的，不产生半保存状态
- [ ] 测量值 `0` 能被正确保存并参与判定，不被存成空
- [ ] 某项只填一两次测量时可保存，并按已填的值判定
- [ ] 某项完全不填时保持「未判定」，不被判成不合格，也不进入不良率分母
- [ ] 编辑已存在的批次时，网格带出原有数据可直接修改
- [ ] 有未保存修改时离开页面会收到提醒
- [ ] 从 03 的明细可直接跳入对应批次的网格并定位到该测试项行
